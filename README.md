Welcome to my **Prolog Programming Collection**! This repository contains a curated set of Prolog programs demonstrating the principles of **logic programming**, **declarative problem solving**, and **artificial intelligence**.

##  About

The programs included in this repository cover fundamental and intermediate Prolog concepts, including:

- Logical inference and rule-based reasoning
- Facts, rules, and queries
- Recursive predicates
- List processing
- Family tree and relationship modeling
- Knowledge representation
- Mathematical and symbolic problem solving
- Classic AI and logic programming exercises

These implementations are intended for learning, experimentation, and academic reference while exploring the declarative programming paradigm.

## 🛠️ Requirements

- SWI-Prolog (Recommended)
- GNU Prolog or any standard Prolog interpreter

##  Getting Started

Clone the repository and load any `.pl` file into your preferred Prolog interpreter.

```prolog
?- consult('filename.pl').
```

Run queries from the Prolog console to explore the implemented logic and observe how Prolog performs automated reasoning.
